Pre-LLM Checks

Evidence before an AI review: build, lint, tests, coverage.

Trust first: the tool is read-only, but repository scripts can do anything. Run --dry-run before a real run on unfamiliar code. v1 has no sandbox.

Run it

py -3 path\to\pre_llm_checks.py --path C:\code\repo --dry-run
py -3 path\to\pre_llm_checks.py --path C:\code\repo

Pipeline

Discover projects -> detect project-defined commands -> Build -> Lint -> Tests -> Coverage -> terminal table + JSON report.

Build failure skips later stages. Lint failure skips Tests and Coverage. Test failure skips Coverage. No tests means Tests SKIP and Coverage FAIL.

Statuses

PASSCommand passed; coverage displays the lowest percentage.FAILCode/tool command failed, or no tests produced coverage failure.WARNSetup or evidence limitation: missing tool, dependencies, linter, or coverage.SKIPNot run because of a gate, no command, no tests, or omitted stage.TIMEOUTStage exceeded its limit; counts as failure.INTRInterrupted with Ctrl+C; report still written.

Useful flags

--steps build,lint,tests,coverage --lint-anyway --verbose --output FILE --add-gitignore --timeout-tests 30m --tail-lines 20 --config FILE

Outputs

  • Terminal table for people.
  • pre-llm-report.json for AI review.
  • Full masked logs under .pre-llm/logs/.

Exit codes

0 pass/warnings only; 1 failure/timeout; 2 tool/config error; 3 no supported project; 130 interrupted.
