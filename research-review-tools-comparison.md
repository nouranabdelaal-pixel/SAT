# AI Review and Security Tools vs. Pre-LLM Checks

Research date: 2026-10-14. This comparison uses first-party product pages and documentation only. A statement marked **Documented** is stated by the linked vendor source. A statement marked **Inference** is a comparison or negative conclusion drawn from what those sources document; it is not a claim that the vendor guarantees the absence of a feature. Product names, plans, and documentation can change.

## Baseline: Pre-LLM Checks (SAT)

**Documented.** Pre-LLM Checks is a local, dependency-free Python CLI. It discovers projects, selects commands defined by each project, runs Build -> Lint -> Tests -> Coverage, prints a human table, and writes `pre-llm-report.json` plus full command logs. The report records statuses, durations, masked commands/output, output tails, log paths, coverage data, warnings, and runner versions. It uses no AI, does not inspect code for defects, and v1 has no CI/remote integration, sandbox, changed-files mode, coverage threshold, or tool-specific finding parsers ([README](SAT-master/SAT-master/README.md), [SPEC](SAT-master/SAT-master/SPEC.md)).

**Inference for this comparison.** SAT is an execution-evidence gate, not a PR reviewer and not a SAST, SCA, dependency, or secret scanner. A passing SAT run means the selected repository commands produced the recorded result; it does not mean the code is secure or defect-free.

### Capability distinctions

- **SAST:** source-code security analysis using code rules/data-flow/etc. None of the cited CodeRabbit, Greptile, Graphite, or Qodo Merge sources explicitly document a conventional SAST engine. Graphite documents AI comments about security issues, which is not enough to infer SAST. Black Duck SCA is not SAST.
- **SCA/dependency scanning:** Black Duck SCA explicitly documents this category. The AI-review products above should not be called SCA tools merely because they can discuss dependencies or security.
- **Secret scanning:** no cited source above establishes a dedicated secret scanner for the named product/review mode. Do not infer it from generic security language.
- **SARIF:** the cited sources do not establish native SARIF output for the four AI PR reviewers. Black Duck output is product/integration-specific; verify the exact edition and connector before claiming SARIF.
- **Reports and dashboards:** Graphite explicitly documents an AI review dashboard and comment feed. Black Duck documents dashboards/reports/policy views. SAT writes a local JSON report and logs. The AI reviewers primarily write to PR review surfaces.

## Bottom line

SAT provides local, deterministic evidence about the repository's own build/lint/tests/coverage commands. CodeRabbit, Greptile, Graphite, and Qodo Merge provide AI semantic PR feedback in code-host review surfaces (with Graphite additionally documenting a review dashboard). Black Duck SCA provides dependency/component, vulnerability, license, and policy analysis. These are complementary layers, not interchangeable definitions of “review.”
