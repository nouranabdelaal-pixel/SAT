Slide 2 · CodeRabbit

CodeRabbit

An AI assistant that reviews pull requests and proposes improvements.

Pull request diff→AI reads changed code + context→PR comments and summary

What it analyzes

  • Changed lines in the pull request.
  • Relevant repository instructions and context.
  • Likely bugs, maintainability issues, and improvements.

What it writes

  • Pull-request summary.
  • Inline review comments.
  • Suggested fixes or code suggestions.
Static analysis? The cited documentation establishes AI PR review, not a conventional SAST engine, SCA engine, or guaranteed secret scanner. Do not treat a CodeRabbit comment as proof that tests passed.

Product · Documentation · Configuration · SAT difference: SAT executes commands; CodeRabbit explains likely issues.

Slide 3 · Greptile

Greptile

AI review and codebase understanding based on an indexed repository.

Repository indexing→PR or question→Context-aware answer/review

What it analyzes

  • Changed code.
  • Related code across the indexed repository.
  • Relationships needed to answer questions or explain behavior.

What it writes

  • Automated pull-request feedback.
  • Natural-language codebase answers.
  • Hosted review results rather than SAT-style local JSON.
Static analysis? Repository indexing and AI reasoning are not automatically SAST. The cited sources do not establish AST/data-flow rules, dependency vulnerability matching, or secret scanning.

Product · Documentation · Integrations · SAT difference: Greptile adds repository context; SAT adds local execution proof.

Slide 4 · Graphite

Graphite Agent

AI review inside a GitHub PR workflow, alongside stacked branches and merge automation.

Pull request→Agent uses codebase context→Inline PR comments + dashboard

What it analyzes

  • Logic bugs and edge cases.
  • Performance and security-like issues.
  • Accidentally committed code and relevant context.

What it writes

  • Inline comments on relevant PR lines.
  • Problem explanation, impact, and fix suggestion.
  • Review dashboard/feed with categories and metrics.
Static analysis? Graphite documents AI comments about vulnerabilities such as SQL injection and XSS, but the cited docs do not establish a conventional SAST/SCA scanner.

AI Reviews · Review comments · SAT difference: Graphite reviews meaning; SAT reports Build/Lint/Tests/Coverage.

Slide 5 · Qodo Merge

Qodo Merge

An AI PR agent for summaries, review comments, suggestions, and configurable workflow actions.

PR + configuration→LLM-assisted review→Comments, suggestions, summary

What it analyzes

  • Pull-request changes.
  • Repository context and configured instructions.
  • Quality, correctness, and improvement opportunities.

What it writes

  • PR comments and suggestions.
  • Summary-style review output.
  • Workflow results controlled by repository configuration.
Static analysis? Qodo Merge is documented here as AI-assisted review. Do not attribute SAST, SCA, license, or secret scanning to Qodo Merge unless a separate documented Qodo product/integration is enabled.

Qodo Merge documentation · SAT difference: Qodo gives semantic feedback; SAT gives reproducible command evidence.

Slide 6 · Black Duck

Black Duck SCA

A security and software-composition tool, not primarily an AI code reviewer.

Dependency/component inventory→Vulnerability + license intelligence→Policy views, alerts, reports, gates

What it analyzes

  • Open-source and third-party components.
  • Versions and dependency relationships.
  • Known vulnerability intelligence.
  • License and compliance risk.

What it writes

  • Central dashboards and risk views.
  • Policy results and alerts.
  • Reports and CI/developer integration results.
Static analysis? SCA is different from SAST. SCA analyzes dependencies/components; SAST analyzes source-code behavior. The cited SCA sources do not establish source-code SAST or dedicated secret scanning.

Black Duck SCA · Integrations · SAT difference: Black Duck analyzes supply-chain security; SAT analyzes repository execution health.

Slide 7 · SAT

Pre-LLM Checks

SAT does not review code meaning. It gathers evidence from the project's own commands.

Discover build files→Detect project commands→Build → Lint → Tests → Coverage→Table + JSON + logs

What it analyzes

  • Command exit status.
  • Timeouts and interruptions.
  • Test and lint output.
  • Fresh coverage reports.
  • Environment/tool versions.

What it writes

  • Terminal project table.
  • Local pre-llm-report.json.
  • Full logs in .pre-llm/logs/.
  • Masked output tails and reasons.
Static analysis? SAT may execute the project's configured linter or analyzer, but SAT itself is not a SAST engine. It reports what that project tool returned.

Slide 8 · terminology

Do not mix these analysis types

AI semantic review

Reasons about code changes using language models and context. Usually writes natural-language comments or summaries.

Examples: CodeRabbit, Greptile, Graphite, Qodo.

SAST

Static Application Security Testing examines source code without executing it, often using rules, ASTs, taint/data-flow, and security patterns.

Examples: A dedicated SAST scanner, not established for the named AI review modes.

SCA

Software Composition Analysis inventories dependencies and compares versions against vulnerability and license intelligence.

Example: Black Duck SCA.

Execution evidence

Runs commands and records whether they passed, failed, timed out, or were skipped.

Example: SAT.
